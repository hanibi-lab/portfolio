# 마녀의 작은 연금술 공방

HTML, CSS, JavaScript 기반의 1인용 연금술 경영 미니게임입니다. AI를 활용하여 기획 및 코드 제작을 진행한 프로토타입이며, 게임 내부의 의뢰와 판정은 규칙 기반입니다.

## 실행 방법

전체 폴더를 내려받아 `index.html`을 브라우저에서 엽니다. 별도 설치나 API 키가 필요하지 않습니다. 인터넷 연결이 없으면 기본 글꼴을 사용합니다.

## 게임 규칙

5일 동안 15명의 손님을 응대합니다. 최대 3개의 재료를 조합하여 회복, 활력, 안정, 집중 효과를 만들고 골드와 평판을 관리합니다.

## 파일 구조

- `index.html`: 화면 구조와 스크립트 로딩
- `css/style.css`: 디자인과 애니메이션
- `js/ingredients.js`: 재료 및 효과 데이터
- `js/customers.js`: 손님 및 의뢰 데이터
- `js/alchemy.js`: 물약 효과 계산 및 제조 판정
- `js/ui.js`: 화면 갱신, 알림 및 모달
- `js/game.js`: 게임 상태, 진행 및 엔딩
- `js/main.js`: 버튼 이벤트 및 초기 실행

스크립트는 HTML에 명시된 순서로 로드합니다. 기존 브라우저 직접 실행 방식을 유지하기 위해 일반 스크립트를 사용합니다.
